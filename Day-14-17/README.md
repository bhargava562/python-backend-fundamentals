# Day 14: Django Fundamentals

## Setup Instructions
1. Clone the repo.
2. Create virtual env: `python -m venv venv`.
3. Activate: `source venv/Scripts/activate`.
4. Install: `pip install django`.
5. Run Migrations: `python manage.py migrate`.
6. Run Server: `python manage.py runserver`.

## Features
- **MVT Architecture**: Implemented for Product Catalog.
- **ORM**: Relationships defined between Categories and Products.
- **Admin Interface**: Configured for data management.
- **Multiple Apps**: `catalog` and `accounts`.
